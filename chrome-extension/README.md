# 🗺️ 네이버 지도 장소 추출기

네이버 지도에서 검색 결과 장소명을 추출하여 저장하는 Chrome Extension입니다.

## ✨ 주요 기능

- 📍 네이버 지도 검색 결과에서 장소명 자동 추출
- 💾 여러 번 검색한 결과를 누적 저장
- 📥 JSON 또는 TXT 파일로 다운로드
- 🔄 중복 자동 제거

## 🚀 설치 방법

### 1. Chrome Extension 개발자 모드로 설치

1. Chrome 브라우저에서 `chrome://extensions/` 접속
2. 우측 상단의 **"개발자 모드"** 토글 활성화
3. **"압축해제된 확장 프로그램을 로드합니다"** 클릭
4. `chrome-extension` 폴더 선택
5. Extension이 설치되면 우측 상단에 아이콘이 표시됩니다

### 2. 아이콘 추가 (선택사항)

Extension에 아이콘을 추가하려면:
1. 128x128 픽셀의 PNG 이미지 준비
2. `icon.png`로 저장하여 `chrome-extension` 폴더에 추가
3. Chrome Extension 페이지에서 새로고침

아이콘이 없어도 Extension은 정상 작동합니다.

## 📖 사용 방법

### 1. 장소 검색 및 추출

1. [네이버 지도](https://map.naver.com)에 접속
2. 검색창에 원하는 검색어 입력 (예: "서울시 사우나")
3. 검색 결과가 표시되면 Chrome Extension 아이콘 클릭
4. **"📍 현재 페이지 추출"** 버튼 클릭
5. 추출된 장소가 목록에 표시됩니다

### 2. 여러 검색 결과 누적

1. 다른 검색어로 검색 (예: "강남구 헬스장")
2. Extension 아이콘 클릭 → **"📍 현재 페이지 추출"** 버튼 클릭
3. 이전 결과에 새로운 장소가 추가됩니다
4. 중복된 장소는 자동으로 제거됩니다

### 3. 데이터 다운로드

- **📥 JSON 다운로드**: 프로그램에서 활용하기 좋은 JSON 형식
  ```json
  {
    "exported_at": "2025-02-08T10:30:00.000Z",
    "total_count": 25,
    "places": [
      "현대프라임 스포츠센터",
      "솔로사우나레포 노량진점",
      ...
    ]
  }
  ```

- **📄 TXT 다운로드**: 일괄 검색용 간단한 텍스트 형식 (한 줄에 장소명 하나씩)
  ```
  현대프라임 스포츠센터
  솔로사우나레포 노량진점
  강남역 카페
  ...
  ```
  → Admin 페이지 "일괄 검색"에 바로 붙여넣기 가능

### 4. 데이터 초기화

- **"모두 삭제"** 버튼: 저장된 모든 장소를 삭제합니다

## 🛠️ 기술 스택

- **Manifest V3**: 최신 Chrome Extension API
- **Chrome Storage API**: 데이터 영구 저장
- **Content Script**: 네이버 지도 페이지에서 DOM 파싱
- **Vanilla JS**: 의존성 없는 순수 JavaScript

## 🐛 문제 해결

### "검색 결과를 찾을 수 없습니다" 오류

**원인**: 검색 결과가 없거나, 페이지가 완전히 로드되지 않았습니다.

**해결 방법**:
1. 검색어를 입력하고 검색 결과가 표시될 때까지 대기
2. 페이지가 완전히 로드된 후 추출 시도
3. 브라우저를 새로고침한 후 다시 시도

### Extension 아이콘이 비활성화됨

**원인**: 네이버 지도 페이지가 아닙니다.

**해결 방법**:
- `https://map.naver.com` 페이지에서만 작동합니다
- URL을 확인하고 네이버 지도 페이지로 이동

### 추출된 장소가 적음

**원인**: 네이버 지도의 DOM 구조 변경 또는 검색 결과가 아직 로드 중입니다.

**해결 방법**:
1. 페이지를 아래로 스크롤하여 더 많은 결과 로드
2. 몇 초 대기 후 다시 추출 시도
3. 개발자 도구(F12) 콘솔에서 오류 확인
