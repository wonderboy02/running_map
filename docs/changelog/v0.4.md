# Changelog v0.4 - BottomDrawer 리스트 뷰 → 탭 + 사진 그리드

**작업일:** 2026-03-05

---

## 주요 변경사항

### 1. DrawerSpotList → DrawerListView 전면 교체

- 기존 텍스트 기반 세로 목록(`DrawerSpotList`)을 **탭 토글 + 사진 그리드 카드**(`DrawerListView`)로 교체
- `DrawerSpotList.tsx` 삭제

### 2. 러너스팟 / 러닝코스 세그먼트 토글

- `rounded-full bg-surface-dim` 컨테이너에 두 탭 배치
- 활성 탭: `bg-primary text-primary-foreground`
- 탭 상태는 `BottomDrawer/index.tsx`에서 lift (selection 전환 시에도 탭 유지)

### 3. 2열(모바일) / 4열(PC) 반응형 카드 그리드

- **SpotGridCard**: `aspect-[3/4]` 세로형 사진, 번호·이름·주소 오버레이, feature 태그
- **CourseGridCard**: `aspect-[4/3]` 지도 썸네일, 거리 배지, 코스명·난이도·설명
- `contentRef`에 첫 4개 아이템, 나머지는 SNAP.FULL에서 노출

### 4. Snap 동작 변경

- 해제(deselect) 시: `SNAP.PEEK` → `SNAP.PREVIEW` (카드 그리드 노출)
- Backdrop tap (FULL에서): `SNAP.PEEK` → `SNAP.PREVIEW` (일관된 동작)
- onClose (드래그 다운): `SNAP.PEEK` 유지

### 5. page.tsx

- `handleDrawerCourseClick` 추가 (drawer_list source로 course_select 이벤트)
- BottomDrawer에 `courses`, `onCourseClick` props 전달
